# Security Policy

This file is the default security policy for every repository in the
ManifoldKit organization that does not define its own `SECURITY.md`.

## Reporting a vulnerability

Please report security vulnerabilities privately — do not open a public
issue or discussion.

Use GitHub's private vulnerability reporting on
[ManifoldKit/ManifoldKit](https://github.com/ManifoldKit/ManifoldKit/security/advisories/new)
("Report a vulnerability" under the Security tab). This works for issues in
any ManifoldKit repository, not just core — if you're unsure where a
vulnerability lives, report it there and it will be routed to the right
repo.

Include as much detail as you can: affected repo/version, a description of
the issue, and steps to reproduce.

## Scope

This policy covers the code in ManifoldKit organization repositories.
Vulnerabilities in third-party dependencies should be reported to the
upstream project as well, where applicable.
